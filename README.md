# Aragatz FPGA Project

Zynq-7000 XC7Z035, Vivado/Vitis 2023.1.

- [Аппаратная регрессия](ps_sw/baremetal/README.md) — отдельное standalone-приложение.
- [Выгрузка конечного захвата через PS Ethernet](ps_sw/lwip_capture/README.md) — сборка, echo и запуск.
- [KSZ9031 / BSP 2023.1](docs/ksz9031_vitis_2023_1.md) — разбор адаптеров и воспроизводимая доработка PHY.
- [Двоичный протокол v1](docs/capture_tcp_v1.md) — запрос 32 байта, заголовок ответа 64 байта.
- [Измерение пропускной способности](docs/ethernet_measurement.md) — сетевой и сквозной тесты.
- [Программная валидация и границы результата](docs/lwip_capture_validation.md).

Рабочий PS preset и адреса периферии сохраняются. Для сборки требуется
актуальная XSA и её сгенерированный `xparameters.h`. Проверки на ПК не заменяют
сборку Vitis, проверку PHY/link и запуск на плате; измеренную скорость публикуют
только вместе с UART и отчётом реального стенда.
